# Spanish Curriculum

## Status

The provisional beginner core has an agreed structure of **30 chapters**, planned at about 15 minutes each (roughly 7.5 hours total). This is a manageable foundation, not a promise of fluency. See [chapter-map.md](chapter-map.md).

The map captures the learner’s preferences: explain how sentences are built, show useful verb forms across persons early, teach question words early, and introduce high-value function words/connectors throughout. Individual explanations, activities, examples, and source references will be developed and checked chapter by chapter. No app lessons have been implemented.

## Materials

Original sources and provenance are kept in [`materials/spanish/`](../../../materials/spanish/), including `SOURCES.md`. Cite selected source locations (FSI volume/unit/page, frequency-list entries, Tatoeba sentence IDs); do not copy full source datasets into the app.
