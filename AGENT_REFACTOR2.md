4. **Add `--resume`.** `python3 run_harness.py --resume` selects the first unchecked task (`--step N` optionally selects another unfinished task). Before changing application files, Sol performs a read-only assessment of current code, tests, evidence, Git changes, and relevant prior run logs. Classify each completion criterion as satisfied, missing, or unverified; do not assume unchecked means unimplemented. Support both uncommitted work and committed partial work, including the current step 15.

Execute only missing work, revalidate existing work rather than recreate it, and update progress after verified actions.
